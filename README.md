# インターネット図書館システム（README試行錯誤中）

## 🚀 概要
専門学校のチーム開発演習で制作したインターネット図書館のWebシステム。複数の小中学校で図書を共有して管理することを想定。本の登録や貸出・返却、予約、運搬管理機能のほか、購読意欲促進のためのランキング機能や貸出禁止期間設定機能などを実装。開発中期からリポジトリで管理。

## 機能一覧
- ログイン・ログアウト
- 書籍新規登録
- 書籍貸出
- 書籍返却
- 書籍予約
- 書籍検索
- 配送管理
- ランキング

## 🛠 技術スタック
* OS: Windows
* 言語: HTML5, CSS3, PHP（8.2）, JavaScript (ES6)
* ライブラリ・フレームワーク: なし（生PHP）
* ブラウザ: Chrome, Microsoft Edge
* サーバ: Docker Desktop

## 最低要件
1. 自校の本を借りて返却することができる
2. 他校の本を取り寄せて借り、返却することができる
3. 他校に貸された本は、必ずその本の所蔵主である学校の図書室に戻す
4. 読書の活性化を促す機能を含む
5. 貸出禁止期間を設定できるようにする（開発終盤での追加要件）


## ✨ こだわり・学習のポイント

書籍の貸出・返却時は、時間的・技術的な制約から、バーコードリーダーではなく書籍ID（ISBNとは別にシステム内で用意したユニークな管理ID）を入力させる方式としています。
予約の優先順位の判断には、FIFO方式を採用しています。
他校の本を取り寄せる場合、たとえ取り寄せる本に一件も予約が入っていなかったとしても、書籍予約でその本を取り寄せ、現地で貸出と返却の処理をする仕様としました。取り寄せ処理を予約処理として扱う事で、「取り寄せ要求」と「予約要求」の優先度を判断する過程を省略し、処理の安定性と開発工程削減を実現しました。また、貸出期限の一部が配送に要した時間で消費されることが原因で、学校の配送距離によっては他校よりも貸出期限が短くなってしまうという不公平な状況の発生を防ぎました。
