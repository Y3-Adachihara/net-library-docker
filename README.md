# インターネット図書館システム

## 概要

在籍する専門学校のチーム開発演習の授業で制作した、インターネット図書館のWebシステムです。

## 開発経緯

開発演習では、以下のような架空の状況が与えられました。

> 
> 
> 
> 某地区には小学校(8校)や中学校(2校)が運営されており、もっとも離れた学校間は約50kmあります。それぞれの学校の図書館（図書室）では、以下に示す三つの問題を抱えています。
> 
> 1. そもそも図書館がない学校があるが、予算がなく手が打てない
> 2. 校内に図書館はあるが、新しい書籍を購入する予算がない
> 3. 生徒の読書機会（読書意欲）が顕著に減少
> 
> そこであなた方は、インターネット上に各学校が利用できる図書館があれば、これらの問題を解決することができるのではと考えました。
> 

この状況を基に、以下のような要件が事前に定義された状態で与えられました。

要件1:    地域の学校間で本が共有される
要件2:   校内の図書を管理する
要件3:   各学校の図書館の管理システムも兼ねる
要件4:   他校へ本を配送する際の配送もシステム化範囲に含む
要件5:   講読意欲を活性化させる

また、開発期間終盤から、以下の要件についても「事前の告知なし」という想定で追加されました。

追加要件:   貸出禁止期間を設定する

これらの要件を満たしながら、さらに細かな要件や仕様は各チームに一任される形で開発がスタートしました。

## 🔴 動作の様子

- **学生ログイン・ログアウト ✅**
    
    **ログイン：**

    ![生徒ログイン_デモ](https://github.com/user-attachments/assets/d9d60cdc-9cdc-4d6b-b7a8-8cb7e74274d3)
    
    localhost/html/student_login.phpにアクセスし、学校とクラス・番号、パスワードを入力します。生徒アカウントを含め、開発で用いたすべてのダミーデータは、以下のような連想配列（生徒データ用配列の先頭のみ抜粋）で定義し、挿入スクリプトで一度に挿入しています。
    
    ```php
    $student_master = [
            // --- 既存データ (ID: 1~15) ---
            ['school_id' => 1, 'grade' => 6, 'class' => 'A', 'number' => 1, 'family_name' => '山田', 'first_name' => '太郎', 'password' => '1234', 'created_at' => '2020-04-01 10:00:00', 'updated_at' => '2025-04-01 10:00:00'],
    ```
    
    ※連想配列のパスワードは平文ですが、挿入時にログイン時の手順と同じハッシュ化を行なっています。また、created_atとupdated_atは、明示的に開発時期の5年前の日時で指定しています。
    
    **ログアウト：**
   　![生徒マイページからログアウト](https://github.com/user-attachments/assets/34ea9a72-c948-4d43-8d8a-5ba0c66c2113)

    

  入力した認証情報に誤りがあった場合、警告ダイアログが表示されます。デモでは、学校やクラス、番号、パスワードなどを変えて試行しています。

    ![生徒ログイン_失敗例](https://github.com/user-attachments/assets/67c80a2a-90f1-47e8-94e3-a50201c4dd81)
